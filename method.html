如何判断一帧是“坏帧”，以及为什么值得加入训练集

本页描述 VFI Hard Miner 当前代码实际执行的判定链。系统不会只看一张误差图，也不会只凭一个深度模型总分收数据； 它先用传统局部结构误差高召回定位，再用冻结 R3D-18 的 CGVQM-2 做时空感知复核，最后通过有效性、可学习性、 错误真实性和严重度四层门控，把确定的训练样本分到 A 或 B。

1. 结论先行：一个样本进入 A/B 必须同时满足什么

validity = accept AND in_scope = accept AND p_solvable ≥ solvable_accept_at AND mining_p_wrong ≥ wrong_accept_at AND 存在具有空间面积的局部候选区域 AND CGVQM error ≥ b_error_at AND（CGVQM 热区与传统区域重合 OR 时序证据足够强）

任一条件不满足，都不会把三帧复制到训练目录。边界样本和传统/深度证据冲突样本进入 Review，只留在 manifest；输入损坏、超出模型能力或明确不困难的样本进入 Reject。

2. 传统局部错误：先回答“prediction 和 GT 到底哪里不同”

记当前模型重建的中间帧为 P，真实中间帧为 GT。所有计算在原始分辨率、RGB [0,1] 上进行。

像素与亮度

RGB(x) = mean_c |P(x,c) - GT(x,c)| Luma(x) = |Y(P(x)) - Y(GT(x))|

RGB 捕获颜色和亮度差；Luma 单独保留人眼更敏感的明暗结构变化。

缺失边缘与新增边缘

missing(x) = max(Sobel(GT) - Sobel(P), 0) extra(x) = max(Sobel(P) - Sobel(GT), 0)

missing 表示 GT 中存在但预测丢失的轮廓；extra 表示预测凭空产生的轮廓。

edge_error(x) = max(missing(x), extra(x)) structure(x) = max(RGB(x), Luma(x), 1.25 × edge_error(x))

不是取全图均值，而是寻找有空间支撑的局部异常

全图均值会把一根断掉的武器、人物手指或 UI 旁的局部撕裂稀释掉。因此系统并行使用两条候选路径： 在 structure 图上取 max(edge_threshold, candidate_quantile) 后提取连通区域，同时使用多尺度滑动窗口 找到“面积较大但单点不尖锐”的异常。面积小于 min_region_pixels、缺少 RGB 支撑或被更强区域完全覆盖的提案会被丢弃。

local_score = max( region_mean, 0.90 × top_10%_mean, 0.95 × top_1%_mean, 0.85 × peak )

p_wrong 保存最强的原始局部错误；mining_p_wrong = p_wrong × priority_weight 才用于挖掘。 贴边、前后帧近似静止且 GT 边缘密度高的文字/图标区域会降低 priority_weight，避免简单 UI 抖动占满训练集； 非 UI 区域仍保留最低名额。

3. 四层高质量门控

输入有效性

三帧必须可解码、尺寸一致、数值有限，编号严格符合 stride。重复帧、镜头切换、跳帧和菜单转场会被拒绝或送审。

模型范围

由双向光流统计大面积出界、遮挡、前景极端运动、流场不连续和不可解释运动。明确超范围的数据不会拿来训练。

可学习性

p_solvable 来自 teacher 恢复能力和 best-of-warp 分支改善。GT 始终定义对错；teacher 只证明“是否有可能修好”。

错误真实性

必须同时存在传统局部区域和 CGVQM 感知证据；两者空间位置冲突且无时序证据时只进入 Review。

为什么这能减少“问题不大”的帧： 单像素噪声过不了最小区域门；普通抗锯齿差异通常过不了 CGVQM error；静态 UI 会被 priority_weight 降权； 传统高分但 CGVQM 低分、或 CGVQM 热区不在传统候选位置的样本都不会进入 A/B。

4. CGVQM-2：用深度时空特征确认“人是否真的能看到劣化”

CGVQM-2 使用冻结的 Kinetics-400 R3D-18。它不参与全量扫描，只复核已经通过传统阈值的候选中心。 对每个中心，在同一视频内取默认 16 个连续 triplet prediction 与对应 GT；视频首尾不足时复制边界位置， 永不跨视频。重叠窗口的 prediction 依赖会合并，相同上下文只重建一次。

候选 crop

系统取主候选 box，向外扩展约 50% 且保证最小边长，再缩放到默认 224×224。这样保留错误周围上下文， 同时把 Conv3D 成本限制在候选区域，不必对整张 4K 图运行 R3D。

R3D 特征距离

输入使用官方均值/标准差。CGVQM-2 读取三层：标准化输入、R3D stem 和 layer1；后两层先沿通道做 L2 归一化。

d_l = Σ_c |w_l,c| × mean_t,h,w (F_l(P) - F_l(GT))² error = α × Σ_l d_l emap = α × Σ_l upsample(Σ_c |w_l,c| × (F_l(P)-F_l(GT))²)

这里使用 error 方向：数值越高，劣化越明显；官方 quality 等于 100 - error。 校准权重来自固定的 cgvqm-2.pickle，R3D 主干和校准文件都由离线 manifest 的大小和 SHA-256 管理， 运行时禁止联网下载。

从时空 error map 提取的证据

字段当前计算用途
center_error中心 map 的 mean、top 1% mean、0.85×peak 取最大避免小型严重结构被均值稀释
temporal_persistence16 个切片中，帧均值达到 B 阈值的比例确认错误不是单点噪声
temporal_change相邻帧均值差的最大值识别突然出现/消失的 flicker
spatial_overlap中心 map top 10% 热点落入传统候选 mask 的比例检查两种方法是否在同一位置看到问题
temporal map逐像素 max |emap[t+1]-emap[t]|可视化时间敏感度
fused mapmax(center map, temporal map)同时展示静态和时序异常

5. “为什么是坏帧”：每一种模型劣化原因如何判定

原因不是从文件名或总分猜出来的。系统先在每个候选区域计算结构、分支和运动证据，再按固定条件贴标签； manifest 的 regions[].metrics 保留支撑数字，reason_confidence 由该区域错误强度乘 UI 优先权得到。

原因当前证据规则防误报约束
missing_part
部件缺失		 missing_edge_error ≥ 0.14，且 missing ≥ 1.25×extra + 0.01。 要求 GT 强轮廓明显消失，而不是预测和 GT 同时存在等量轻微边缘位移。
broken_structure
结构断裂		 missing 达阈值，并且预测边缘端点更多、连通块更多，或候选为长宽比至少 1.75 的细长断裂结构。 必须先有明确缺失边缘，普通纹理颜色误差不会触发。
ghosting
重影/双轮廓		 missing 和 extra 都达到 0.14，且二者强度比在 0.35～2.85。 要求“旧轮廓缺失 + 新轮廓出现”同时成立，单侧模糊不算重影。
edge_tearing
边缘撕裂		 边缘误差达到 0.14，并且错误边缘与 flow 梯度或 mask 梯度的强突变区重合比例至少 0.25。 旧版“任何边缘误差都算撕裂”已移除；没有模型运动/融合证据时不贴该标签。
blur
细节模糊		 missing 达阈值，且 GT 局部边缘强度比 prediction 至少高 branch_improvement=0.08。 要求 GT 的高频细节确实更强，不把纯亮度偏差写成 blur。
endpoint_copy
端点帧复制		 prediction 到 img1 的局部距离远小于 prediction 到 GT；默认至少改善当前错误的 65%。 当前错误还必须达到最小错误阈值，正常静止画面不会仅因相似而触发。
blend_mask_error
融合权重错误		 warp0/warp1 中至少一条分支比最终 warp blend 好 0.08 以上。 说明运动分支已经能恢复 GT，错误主要由 mask 融合放大；不是凭最终图猜 mask。
flicker
时序闪烁		 CGVQM 相邻帧 error 均值的最大变化达到 flicker_change_at（默认 10）。 必须来自连续预测窗口，不再根据单个三帧样本独立推断闪烁。
原因标签用于解释与 A 级结构证据，不会绕过质量门。即使出现 missing_part，只要输入无效、 p_solvable 不足、CGVQM 低或空间位置冲突，仍不会进入训练目录。

6. A、B、Review、Reject 的最终分级

A

大幅结构/时序劣化。必须满足 CGVQM error ≥ A 阈值、传统错误 ≥ severe 阈值，并具有强结构原因或强时序证据。

B

确定存在但程度较轻。必须超过 B 的传统和 CGVQM 阈值，并通过空间重合或时序确认；不是“剩下的都放 B”。

Review

阈值灰区、传统/CGVQM 总分冲突、两者位置冲突或缺少深度证据。只写 manifest，等待人工抽检。

Reject

无效、超范围、不可学习、没有局部支撑或错误不足。不会复制训练帧。

A = common_quality_gate AND cgvqm_error ≥ a_error_at AND mining_p_wrong ≥ severe_wrong_accept_at AND (strong_structure OR strong_temporal_evidence) B = common_quality_gate AND cgvqm_error ≥ b_error_at AND (spatial_overlap ≥ spatial_overlap_at OR strong_temporal_evidence) AND NOT A

7. 训练数据如何复制：按坏帧中心独立分级，不再生成三元组子目录

第 2 帧预测为 A：原始帧 1、2、3 → extremely_hard_case/A/ 第 4 帧预测为 B：原始帧 3、4、5 → extremely_hard_case/B/

因此原始第 3 帧同时出现在 A 与 B 是正确行为：它分别服务两个不同等级的训练中心。同级内部重叠取并集， 只复制一次。A/B 内没有视频、segment、01/02 或自动编号子目录，basename 原样保留。

字节保真

训练帧使用 copy2 复制到同目录临时文件，再原子改名；完成后比较大小和 SHA-256。训练图片不会转成 JPEG。

冲突保护

同一等级中，不同源文件若映射到相同 basename，任务明确失败；不会覆盖、自动改名或悄悄混合两个视频。

按视频增量

一个视频 CGVQM 完成后立即写入 .vfi_hard_miner_staging/<execution_id>/hard_case/A|B。

原子发布

全部精判、诊断、manifest 和校验成功后才切换正式目录；失败保留上一版，重跑只补缺失步骤。

9. 一键执行与恢复

vfi-hard-miner run --config configs/my_game.json

一条命令内部依次执行 index → main → 可选 teacher → CGVQM → finalize。main 和 CGVQM 都有独立 SQLite 状态、 任务租约、attempt 结果与 30 秒日志心跳。解码 batch 保持 uint8，NPU 主推理只 stack 固定网络分辨率 Tensor； 原分辨率 float32 只为已通过 postproc_buffer_mb 准入的 reconstruction 微批次创建。 预算覆盖 18 通道重建结果、9 通道输入、评分 scratch 和 endpoint stack transient。 invalid、out-of-scope 与明显简单样本跳过 branch diagnosis；训练级样本仍完成全部质量门。 warp/endpoint evidence 只计算带 1 px halo 的候选 crop，flow scope 保持全分辨率。 日志显示 decode_uint8、network、reconstruction_transient、retained/reserved 与 resident_estimate， 并周期汇总 decode、inference、reconstruction、Future wait 和四个 CPU 子阶段的 ms/sample。

分阶段命令仍保留用于故障恢复：index、mine、teacher、 cgvqm、finalize。日常运行只推荐 run。

10. A3 首轮抽检与阈值调节

  1. 对同一 chunk 分别测试 model.batch_size=16/32/64，以完整墙钟时间最短为准，不只比较 NPU inference。
  2. 同时比较每 worker 1/2 个 postprocess Future；观察 resident_estimate、进程 RSS、swap 和八阶段 ms/sample。
  3. 先看 Review 中的 CGVQM error、spatial_overlap、temporal_persistence 分布，不要直接降低所有阈值。
  4. A 中若仍有轻微帧，优先提高 severe_wrong_accept_at 或 a_error_at；不要降低 B 来“补数量”。
  5. B 中若有抗锯齿/UI 误报，优先提高 spatial_overlap_at、b_error_at，并检查 priority_weight。
  6. 漏掉真实闪烁时，人工确认连续窗口后再调整 flicker_change_at 或 temporal_persistence_at。
  7. 每次阈值或模型变化都会改变 run hash；使用新的 runtime.run_dir，不能混用旧结果。
不应把“输出数量多”当成质量目标。A/B 是直接供训练读取的数据；Review 才是扩召回和人工校准的缓冲区。 首轮 A3 验收应分别随机抽查 A、B、Review，并以误入 A/B 的简单帧比例作为主要质量指标。
